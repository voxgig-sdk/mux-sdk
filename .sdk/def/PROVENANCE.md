## Why this SDK exists

It is on the admin repository's **vergleich** list: SDKs built with the Voxgig
toolchain to compare it with the generators on voxgig.com/sdk/comparisons, one
API per generator. This one is compared with **Stainless**.

- **Compared with:** muxinc/mux-node-sdk, `@mux/ts` 15.3.0 with the MCP server `@mux/mcp` 15.3.0, generated with Stainless's `stlc`. Mux's Python, Go, Ruby, Java and PHP SDKs are OpenAPI Generator output.
