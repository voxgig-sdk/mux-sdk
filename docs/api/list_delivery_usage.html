list

GET /video/v1/delivery-usage

Operation ID: list-delivery-usage.

Authentication: basic token (accessToken) or bearer token (authorizationToken).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | page | query | integer (int32) | No | Offset by this many pages, of the size of limit | | limit | query | integer (int32) | No | Number of items to include in the response | | asset_id | query | string | No | Filter response to return delivery usage for this asset only. You cannot specify both the asset_id and live_stream_id parameters together. | | live_stream_id | query | string | No | Filter response to return delivery usage for assets for this live stream. You cannot specify both the asset_id and live_stream_id parameters together. | | timeframe[] | query | array of string | No | Time window to get delivery usage information. timeframe[0] indicates the start time, timeframe[1] indicates the end time in seconds since the Unix epoch. Default time window is 1 hour representing usage from 13th to 12th hour from when the request is made. |
