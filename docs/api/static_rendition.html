Responses

201: Created

application/json

Property Type Required Description
data object Yes
data.bitrate integer (int64) No The bitrate in bits per second
data.ext enum: mp4, m4a No Extension of the static rendition file
data.filesize string (int64) No The file size in bytes
data.height integer (int32) No The height of the static rendition's file in pixels
data.id string No The ID of this static rendition, used in managing this static rendition. Only present for static renditions created with the Static Renditions API. Not set for renditions created with the deprecated mp4_support option.
data.name enum: low.mp4, medium.mp4, high.mp4, highest.mp4, audio.m4a, capped-1080p.mp4, ... No Name of the static rendition file
data.passthrough string No Arbitrary user-supplied metadata set for the static rendition. Max 255 characters.
data.resolution enum: highest, audio-only, 2160p, 1440p, 1080p, 720p, ... No Indicates the resolution of this specific MP4 version of this asset. Only present for static renditions created with the Static Renditions API. Not set for renditions created with the deprecated mp4_support option.
data.resolution_tier enum: 2160p, 1440p, 1080p, 720p, audio-only No Indicates the resolution tier of this specific MP4 version of this asset. Only present for static renditions created with the Static Renditions API. Not set for renditions created with the deprecated mp4_support option.
data.status enum: ready, preparing, skipped, errored No Indicates the status of this specific MP4 version of this asset. Only present for static renditions created with the Static Renditions API. Not set for renditions created with the deprecated mp4_support option. For mp4_support renditions, see the top-level ``static_renditions.status field on the asset instead. * ready indicates the MP4 has been generated and is ready for download * preparing indicates the asset has not been ingested or the static rendition is still being generated after an asset is ready * skipped indicates the static rendition will not be generated because the requested resolution conflicts with the asset attributes after the asset has been ingested * errored indicates the static rendition cannot be generated. For example, an asset could not be ingested
data.type enum: standard, advanced No Indicates the static rendition type of this specific MP4 version of this asset. Only present for static renditions created with the Static Renditions API. Not set for renditions created with the deprecated mp4_support option.
data.width integer (int32) No The width of the static rendition's file in pixels
