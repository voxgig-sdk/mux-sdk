create

POST /robots/v0/jobs/edit-captions

Operation ID: create-edit-captions-job.

Authentication: basic token (accessToken) or bearer token (authorizationToken).

Request body

application/json

Property Type Required Description
parameters object Yes
parameters.asset_id string Yes The Mux asset ID whose existing text track should be edited.
parameters.auto_censor_profanity object No Optional LLM-driven profanity detection and censorship rules applied to the selected caption track.
parameters.auto_censor_profanity.always_censor array of string No Additional words or short phrases that should always be censored even if the model does not detect them.
parameters.auto_censor_profanity.detection_method enum: llm No How profanity is detected. Currently only llm is supported, which uses an LLM to identify profanity in cue text.
parameters.auto_censor_profanity.mode enum: blank, remove, mask No Replacement strategy for detected profanity: blank inserts bracketed underscores, remove drops the match, and mask replaces characters with question marks. Defaults to "blank".
parameters.auto_censor_profanity.never_censor array of string No Words or short phrases that should never be censored even if the model flags them.
parameters.delete_original_track boolean No Whether to delete the original source text track after the edited track upload succeeds. Has effect only when upload_to_mux is true. Defaults to true.
parameters.replacements array of object No Optional static word or phrase replacements applied directly to cue text.
parameters.replacements[].case_sensitive boolean No When true, find is matched only with exact case. Defaults to false (case-insensitive matching), so "gonna" also matches "Gonna" and "GONNA".
parameters.replacements[].find string Yes Exact word or phrase to replace in cue text.
parameters.replacements[].replace string Yes Replacement text to insert when a match is found.
parameters.speaker_replacements array of object No Optional replacements for bracketed speaker labels at the start of caption cues. Values omit the surrounding square brackets, and matching spoken text is not changed.
parameters.speaker_replacements[].find string Yes Existing speaker label without the surrounding square brackets.
parameters.speaker_replacements[].replace string Yes New speaker label without the surrounding square brackets.
parameters.track_id string Yes The existing ready Mux text track ID to edit and optionally replace.
parameters.track_name_suffix string No Optional suffix appended to the uploaded replacement track name. Defaults to "edited".
parameters.upload_to_mux boolean No Whether to upload the edited VTT back to the Mux asset as a new text track. Defaults to true.
passthrough string No Arbitrary string stored with the job and returned in responses. Useful for correlating jobs with your own systems.

Example request body:

{
  "parameters": {
    "asset_id": "mux_asset_123abc",
    "delete_original_track": true,
    "replacements": [
      {
        "case_sensitive": true,
        "find": "Mucks",
        "replace": "Mux"
      },
      {
        "find": "gonna",
        "replace": "going to"
      }
    ],
    "speaker_replacements": [
      {
        "find": "speaker_0",
        "replace": "Alice"
      }
    ],
    "track_id": "text_track_456def",
    "upload_to_mux": true
  }
}
