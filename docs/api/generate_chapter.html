create

POST /robots/v0/jobs/generate-chapters

Operation ID: create-generate-chapters-job.

Authentication: basic token (accessToken) or bearer token (authorizationToken).

Request body

application/json

Property Type Required Description
parameters object Yes
parameters.asset_id string Yes The Mux asset ID of the video to generate chapters for.
parameters.language_code string No BCP 47 language code of the caption track to analyze (for example "en", "fr"). When omitted, the SDK prefers English if available.
parameters.output_language_code string No BCP 47 language code for the output chapter titles. Auto-detected from the transcript if omitted.
parameters.output_steering object No Curated output_steering controls for chapter style, granularity, audience, and brand terminology. These controls guide model behavior but do not guarantee exact output.
parameters.output_steering.audience string No Intended audience used as best-effort model guidance. Does not change the output schema.
parameters.output_steering.brand_terms array of string No Preferred brand or domain terms to use when supported by the source content.
parameters.output_steering.chapter_granularity enum: coarse, balanced, fine No Best-effort guidance for how coarse or fine chapter boundaries should be.
parameters.output_steering.chapter_style enum: descriptive, punchy, educational, seo, platform_neutral No Best-effort style guidance for generated chapter titles.
parameters.prompt_overrides object No Deprecated: use output_steering. Raw prompt-section overrides; any section supplied here takes precedence over the equivalent output_steering guidance.
parameters.prompt_overrides.chapter_guidelines string No Override the chapter density and timing constraints.
parameters.prompt_overrides.output_format string No Override the JSON output format instructions.
parameters.prompt_overrides.task string No Override the core task instruction for chapter generation.
parameters.prompt_overrides.title_guidelines string No Override the chapter title style requirements.
parameters.update_asset_chapters boolean No When true, the generated chapters are written back to the Mux asset as a chapters text track once the job completes, making them deliverable with the asset. Overwrites existing chapters: an asset holds a single chapters track, so any chapters track already on the asset is deleted and replaced, including one in a different language, and one you created yourself. Best-effort, a failed write does not fail the job, so check asset_update in the job outputs for the outcome.
passthrough string No Arbitrary string stored with the job and returned in responses. Useful for correlating jobs with your own systems.

Example request body:

{
  "parameters": {
    "asset_id": "mux_asset_123abc",
    "output_steering": {
      "audience": "Developers",
      "chapter_granularity": "balanced",
      "chapter_style": "descriptive"
    },
    "update_asset_chapters": true
  }
}
