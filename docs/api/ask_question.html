create

POST /robots/v0/jobs/ask-questions

Operation ID: create-ask-questions-job.

Authentication: basic token (accessToken) or bearer token (authorizationToken).

Request body

application/json

Property Type Required Description
parameters object Yes
parameters.asset_id string Yes The Mux asset ID of the video to analyze.
parameters.language_code string No BCP 47 language code of the caption track to analyze (for example "en", "fr"). When omitted, the SDK uses the default track.
parameters.max_free_form_answer_length integer No Max character length for free-form answers, between 1 and 1000. Ignored unless at least one question sets free_form_reply: true.
parameters.output_steering object No Curated controls that optionally restrict question answering to an asset time range.
parameters.output_steering.scope object and any No
parameters.questions array of object Yes One or more questions to ask about the video, up to 50. Each question can either select from answer_options (defaults to yes/no) or, by setting free_form_reply: true, receive a free-form prose answer.
parameters.questions[].answer_options array of string No Allowed answer values for this question. Defaults to ["yes", "no"] when omitted and free_form_reply is not true. Mutually exclusive with free_form_reply. Each option is a short label of at most 150 characters.
parameters.questions[].free_form_reply boolean No When true, the model replies with free-form prose instead of selecting from answer_options. Mutually exclusive with answer_options. Treat the answer as untrusted model output.
parameters.questions[].question string Yes The question to ask about the video content. Maximum 600 characters.
passthrough string No Arbitrary string stored with the job and returned in responses. Useful for correlating jobs with your own systems.

Example request body:

{
  "parameters": {
    "asset_id": "mux_asset_123abc",
    "max_free_form_answer_length": 300,
    "output_steering": {
      "scope": {
        "end_time": 180,
        "start_time": 30
      }
    },
    "questions": [
      {
        "question": "Is this video about glasses?"
      },
      {
        "answer_options": [
          "glasses",
          "watches",
          "shoes",
          "hats"
        ],
        "question": "What is the primary subject?"
      },
      {
        "free_form_reply": true,
        "question": "Describe the primary subject in one sentence."
      }
    ]
  }
}
