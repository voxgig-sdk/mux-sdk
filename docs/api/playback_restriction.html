create

POST /video/v1/playback-restrictions

Operation ID: create-playback-restriction.

Authentication: basic token (accessToken) or bearer token (authorizationToken).

Request body

application/json

Property Type Required Description
referrer object Yes A list of domains allowed to play your videos.
referrer.allow_no_referrer boolean No A boolean to determine whether to allow or deny HTTP requests without Referer HTTP request header. Playback requests coming from non-web/native applications like iOS, Android or smart TVs will not have a Referer HTTP header. Set this value to true to allow these playback requests.
referrer.allowed_domains array of string Yes List of domains allowed to play videos. Possible values are * [] Empty Array indicates deny video playback requests for all domains * [&quot;*&quot;] A Single Wildcard * entry means allow video playback requests from any domain * [&quot;*.example.com&quot;, &quot;foo.com&quot;] A list of up to 10 domains or valid dns-style wildcards
user_agent object Yes Rules that control what user agents are allowed to play your videos. Please see Using User-Agent HTTP header for validation for more details on this feature.
user_agent.allow_high_risk_user_agent boolean No Whether or not to allow high risk user agents. The high risk user agents are defined by Mux.
user_agent.allow_no_user_agent boolean No Whether or not to allow views without a User-Agent HTTP request header.

Example request body:

{
  "referrer": {
    "allow_no_referrer": true,
    "allowed_domains": [
      "*.example.com"
    ]
  },
  "user_agent": {
    "allow_high_risk_user_agent": false,
    "allow_no_user_agent": false
  }
}
