create

POST /robots/v0/jobs/summarize

Operation ID: create-summarize-job.

Authentication: basic token (accessToken) or bearer token (authorizationToken).

Request body

application/json

Property Type Required Description
parameters object Yes
parameters.asset_id string Yes The Mux asset ID of the video to summarize.
parameters.description_length integer No Maximum description length in words.
parameters.language_code string No BCP 47 language code of the caption track to analyze (for example "en", "fr"). When omitted, the SDK uses the default track.
parameters.output_language_code string No BCP 47 language code for the generated summary output (for example "en", "fr", "ja"). Auto-detected from the transcript if omitted.
parameters.output_steering object No Curated output_steering controls for execution scope, summary style, audience, brand terminology, and tag taxonomy. Scope is enforced; other controls guide model behavior but do not guarantee exact output.
parameters.output_steering.audience string No Intended audience used as best-effort model guidance. Does not change the output schema.
parameters.output_steering.brand_terms array of string No Preferred brand or domain terms to use when supported by the source content.
parameters.output_steering.scope object No Optional execution window in seconds on the original asset timeline. Omit start_time to begin at the asset start and omit end_time to continue through the asset end. The summary and tags are generated only from media within this window.
parameters.output_steering.scope.end_time number No End of the execution window in seconds from the beginning of the media. When omitted, the window extends to the end.
parameters.output_steering.scope.start_time number No Start of the execution window in seconds from the beginning of the media. When omitted, the window starts at the beginning.
parameters.output_steering.summary_style enum: concise, detailed, editorial No Best-effort style guidance for the generated title and description.
parameters.output_steering.tag_taxonomy object No Controlled vocabulary for tag generation. This steers tags and may be deterministically filtered after generation. Supports up to 50 values and 2000 serialized characters.
parameters.output_steering.tag_taxonomy.allow_other boolean Yes When false, generated tags are filtered to taxonomy labels and aliases. When true, unmatched tags may remain.
parameters.output_steering.tag_taxonomy.name string No Optional customer-facing name for the taxonomy, up to 100 characters.
parameters.output_steering.tag_taxonomy.values array of object Yes Controlled vocabulary values for generated tags. Supports 1-50 values.
parameters.output_steering.tag_taxonomy.values[].aliases array of string No Accepted alternate names that should normalize to the canonical label. Up to 10 aliases, each up to 100 characters.
parameters.output_steering.tag_taxonomy.values[].description string No Short explanation of when this tag applies, up to 300 characters.
parameters.output_steering.tag_taxonomy.values[].label string Yes Canonical tag value to prefer in generated tags, up to 100 characters.
parameters.prompt_overrides object No Deprecated: use output_steering. Raw prompt-section overrides; any section supplied here takes precedence over the equivalent output_steering guidance.
parameters.prompt_overrides.description string No Override the description generation requirements.
parameters.prompt_overrides.keywords string No Override the keyword/tag extraction requirements.
parameters.prompt_overrides.quality_guidelines string No Override the quality standards for analysis.
parameters.prompt_overrides.task string No Override the core task instruction for summarization.
parameters.prompt_overrides.title string No Override the title generation requirements.
parameters.tag_count integer No Maximum number of tags to include in the generated output. Defaults to 10.
parameters.title_length integer No Maximum title length in words.
parameters.tone enum: neutral, playful, professional No Tone for the generated summary. "neutral" for straightforward analysis, "playful" for witty and conversational, "professional" for executive-level reporting.
parameters.update_asset_meta boolean No When true, the generated title is written to the Mux asset's metadata (asset.meta.title) once the summary completes. Best-effort: a metadata-write failure does not fail the summary.
passthrough string No Arbitrary string stored with the job and returned in responses. Useful for correlating jobs with your own systems.
