create

POST /robots/v0/jobs/find-key-moments

Operation ID: create-find-key-moments-job.

Authentication: basic token (accessToken) or bearer token (authorizationToken).

Request body

application/json

Property Type Required Description
parameters object Yes
parameters.asset_id string Yes The Mux asset ID of the video to analyze.
parameters.max_moments integer No Maximum number of key moments to extract. When omitted, defaults to 10 for assets up to one hour and 25 for longer assets.
parameters.output_steering object No Curated output_steering controls for execution scope, selection strategy, title style, audience, taxonomy, and rubric tie-breakers. Scope is enforced; other controls guide model behavior but do not guarantee exact output.
parameters.output_steering.audience string No Intended audience used as best-effort model guidance. Does not change the output schema.
parameters.output_steering.brand_terms array of string No Preferred brand or domain terms to use when supported by the source content.
parameters.output_steering.rubric_priorities array of enum: clarity_in_isolation, emotional_intensity, novelty, soundbite_quality No Rubric dimensions to use as tie-breakers after applying selection strategy. Best-effort guidance only.
parameters.output_steering.scope object and any No
parameters.output_steering.selection_strategy enum: standalone_hooks, educational_takeaways, story_beats, product_moments, speaker_highlights No Best-effort guidance for what qualifies as a strong standalone key moment.
parameters.output_steering.title_style enum: descriptive, punchy, educational, social No Best-effort title style guidance for generated moment titles.
parameters.output_steering.topic_taxonomy object and any No
parameters.target_duration_ms object No Preferred highlight duration range in milliseconds. When provided, the model will aim to select moments within this range.
parameters.target_duration_ms.max integer Yes Preferred maximum highlight duration in milliseconds.
parameters.target_duration_ms.min integer Yes Preferred minimum highlight duration in milliseconds.
parameters.use_shots boolean No Controls whether video assets are analyzed using Mux shots. When true, shots are generated or reused and visual evidence drives selection. When false or omitted, selection uses transcript evidence and the asset must have a caption track. Not supported for audio-only assets.
passthrough string No Arbitrary string stored with the job and returned in responses. Useful for correlating jobs with your own systems.
