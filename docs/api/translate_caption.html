create

POST /robots/v0/jobs/translate-captions

Operation ID: create-translate-captions-job.

Authentication: basic token (accessToken) or bearer token (authorizationToken).

Request body

application/json

Property Type Required Description
parameters object Yes
parameters.asset_id string Yes The Mux asset ID of the video whose captions will be translated.
parameters.never_translate array of string No Best-effort list of terms (brand names, proper nouns) to preserve verbatim in the translated captions. Does not guarantee exact output. Terms must not contain '<' or '>', invisible characters, or characters altered by Unicode normalization.
parameters.replace_existing_tracks enum: fail, replace_all, replace_generated No What to do when the asset already has a text track in the same language as, or with the same name as, the translated track. Defaults to fail, which rejects the request before any translation is billed. replace_all deletes every such track first. replace_generated deletes only Mux Video auto-generated tracks and rejects if an uploaded track is in the way. Any value other than fail requires upload_to_mux to be true. Existing tracks are matched by language ignoring region subtags, and by name ignoring case, in any status.
parameters.to_language_code string Yes BCP 47 language code for the translated output (for example "es", "ja"). Unless replace_existing_tracks allows replacement, the asset must not already have a text track for this language.
parameters.track_id string Yes The Mux text track ID of the source caption track to translate. The asset must have a ready text track matching this ID or the request will be rejected.
parameters.upload_to_mux boolean No Whether to upload the translated VTT and attach it as a text track on the Mux asset. Defaults to true.
passthrough string No Arbitrary string stored with the job and returned in responses. Useful for correlating jobs with your own systems.

Example request body:

{
  "parameters": {
    "asset_id": "mux_asset_123abc",
    "never_translate": [
      "Mux"
    ],
    "replace_existing_tracks": "fail",
    "to_language_code": "es",
    "track_id": "track_en_abc123",
    "upload_to_mux": true
  }
}
