list

GET /video/v1/assets

Operation ID: list-assets.

Authentication: basic token (accessToken) or bearer token (authorizationToken).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | limit | query | integer (int32) | No | Number of items to include in the response | | page | query | integer (int32) | No | Offset by this many pages, of the size of limit | | cursor | query | string | No | This parameter is used to request pages beyond the first. You can find the cursor value in the next_cursor field of paginated responses. | | live_stream_id | query | string | No | Filter response to return all the assets for this live stream only | | upload_id | query | string | No | Filter response to return an asset created from this direct upload only |
